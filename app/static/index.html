Chest X-ray screening

A fine-tuned ResNet18 sorts a chest radiograph into normal or pneumonia, and shows how close the call was.

The result appears here once an image is submitted. Nothing is stored — each image is read, classified, and discarded.

Built for a data-mining course assignment. On the held-out test set this model reached 84.9% accuracy and 0.822 macro F1, but caught only 60.7% of genuinely normal chests — it leans toward flagging pneumonia. Read a flag as a reason to look closer, never as a diagnosis.
